Крестики-нолики на C++ 
проект:
Создание игры " tic-tac-toe" на C++. Для этого мы будем использовать язык программирования C++ и чтобы в нее можно было играть в браузере, с помощью,  Emscripten, которая позволяет компилировать C++ код в формат, используемый для браузеров.

очень коротко о задачах (?):
1. создание кода в GitHub всей командой
"крестики-нолики" 3×3 с такими возможностями(?):
два игрока по очереди ставят крестики и нолики
проверка победителя после каждого хода
определение ничьей

3. особенности проекта(?)
игра написана на C++/C, потому что нам так сказали
мы постараемся перевести с помощью Emscripten перевести нашу игру в браузер  (C++ >>> JavaScript)
проект ( в идеале) можно открыть на любом ноутбуке или телефоне с (современным) браузером

как в идеале все должно работать:
пользователь открывает наш сайт в браузере
ему выпадает крестик или нолик(за что он будет играть)
когда игрок кликает по клетке:
JavaScript передаёт информацию о ходе в C++ 
C++ код проверяет ход и обновляет игровое поле
C++ проверяет, есть ли победитель, после этого хода
результат возвращается в JavaScript и обновляется интерфейс
